Onboarding

희망나눔이 당신에게 맞는 프로그램을 찾아드릴게요.

카테고리, 지역, 정기 여부, 긴급 선호, 키워드를 알려주시면 RAG 기반으로 유사한 프로그램을 우선 추천합니다.

  • 선택한 카테고리/지역을 중심으로 큐레이션
  • 정기/단발 선호와 긴급 캠페인 우선도 반영
  • 지금 돕고 싶은 키워드는 텍스트 임베딩 비교에 사용
Q1

복수선택 가능

어떤 관심 분야에 후원하고 싶나요?

선택한 카테고리는 donor_preference.preferred_category_id로 저장됩니다.

Q2

단일 선택

정기 여부를 알려주세요.
Q3

복수선택 가능

선호하는 지역은 어디인가요?

선택 지역은 donor_preferred_region에 여러 행으로 저장 후 program.place와 매칭됩니다.

Q4

단일 선택

긴급 캠페인을 우선적으로 보고 싶으신가요?
Q5

자유 입력

지금 특히 돕고 싶은 키워드

입력한 키워드는 텍스트 임베딩 후 프로그램 설명과 유사도 비교에 활용됩니다.

* 첫 로그인에만 뜨는 팝업입니다. 나중에 마이페이지에서 수정 가능.
